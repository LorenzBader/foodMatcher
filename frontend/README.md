# food_matcher

I have written a script to start the project (start.js in backend). It sets all variables and credentials, builds the vue project, copies files and runs the server. The credentials are written in plain text. I don't care if you have them (this user doesn't have admin privileges).

## Project Setup
run npm install in the frontend and backend folder

```sh
npm install
```

### Compile and Run
Run npm run start in the backend folder

```sh
npm run start
```
### Another way to start
in vs-code it is possible to start the project by opening the package.json file in the backend and clicking on the debug button whicha appears above scripts tag.
